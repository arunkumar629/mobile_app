# Mobile App - Flask Server

A simple Flask web application that returns a greeting message.

## Requirements

- Python 3.x
- Flask

## Installation

```bash
pip install flask
```

## Usage

```bash
python app.py
```

The server starts on `http://0.0.0.0:80`.

## Endpoints

| Method | Path | Response |
|--------|------|----------|
| GET    | `/`  | `hello arun` |
